# Reporte paso 3.7 — Registro público de equipos

## Resumen

Se habilitó el registro público de equipos: visitantes sin cuenta pueden solicitar inscripción desde `/publico/[organizationId]/[seasonSlug]/inscribir` cuando el organizador activa el toggle en la configuración del torneo. Las solicitudes quedan pendientes; el admin aprueba (crea equipo nuevo, inscribe en la temporada e invita al capitán con el flujo existente) o rechaza con motivo. El dashboard de pendientes incluye una 6.ª categoría.

## Decisiones tomadas

1. **Toggle solo en torneos públicos:** el checkbox de registro público aparece en «Editar configuración» únicamente cuando `visibility = public`, coherente con que `__resolve_public_season` exige temporada pública.
2. **`is_public_team_registration_open` RPC:** helper anon-callable para que la página pública valide disponibilidad sin SELECT directo a `season_rules`.
3. **Aprobación siempre crea equipo nuevo:** `approve_team_registration_request` hace `INSERT INTO teams` antes de `enroll_team_in_season`, sin deduplicar equipos existentes (alcance del prompt).
4. **Actualización de `season_rules` vía update directo:** el toggle no pasa por `update_season_with_rules` (igual que `groups_advance_per_group`).
