## Resumen

Se clonó el patrón de `organizations.logo_path` / bucket `organization-logos` para escudos de equipo:

- Columna `teams.logo_path` con CHECK `{org_id}/{team_id}/{uuid}.(png|jpg|jpeg|webp)`
- Función `is_valid_team_logo_path`, RPC `set_team_logo`
- Bucket público `team-logos` (2 MB, png/jpeg/webp) con políticas INSERT/SELECT/DELETE para admin/owner validando org + team
- `setTeamLogoAction`, `TeamLogoUploader`, helpers de URL pública
- Componentes reutilizables `TeamCrest` y `TeamMatchupTitle`

## Pantallas con escudo visible

| Pantalla | Componente |
|----------|------------|
| Listado de equipos (`/equipos`) | `TeamCard` + `TeamCrest` |
| Ficha de equipo (`/equipos/[teamId]`) | `TeamCrest` en encabezado |
| Edición de equipo (`/equipos/[teamId]/editar`) | `TeamLogoUploader` (subir/quitar) |
| Detalle de partido (org) | `TeamMatchupTitle` en `PageHeader` |
| Captura de partido | `MatchCaptureHeader` → `TeamMatchupTitle` |
| Calendario interno (tarjetas de partido) | `MatchCard` → `TeamMatchupTitle` |
| Detalle público de partido (`/publico/.../partidos/[matchId]`) | `PublicMatchDetailView` → `TeamMatchupTitle` |

## Pantallas sin escudo (sin componente común de nombre de equipo)

| Pantalla | Motivo |
|----------|--------|
| Calendario público (`/publico/.../calendario`) | Nombres inline en la página, sin componente compartido |
| Resultados recientes / próximos partidos públicos | `PublicRecentResults`, `PublicUpcomingMatches` — texto inline |
| Posiciones, goleadores, disciplina (público e interno) | Tablas con `teamName` como celda de texto |
| Formularios de captura (marcador, eventos, plantel) | Labels por equipo sin componente de escudo |
| Bracket eliminatorio | `KnockoutBracketView` — nombres por slot |
| Vistas de capitán / invitación arbitral | Nombres en labels sueltos |
