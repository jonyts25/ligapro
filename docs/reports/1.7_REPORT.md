## Resumen

Al validar plantel (web `MatchRosterValidationForm`, mobile captura del árbitro), cada jugador con suspensión activa muestra un aviso visible **"Suspendido — N partidos"** en color de advertencia. La validación **no se bloquea**: el árbitro o admin puede marcarlo como `played` igual.

## Migración

`supabase/migrations/20260927220000_match_roster_eligibility.sql`:

- RPC `get_match_roster_eligibility(p_match_id)` → filas por `season_team_player_id` de ambos equipos
- `is_suspended`: true si existe al menos una fila en `discipline_suspensions` con `status = 'active'`
- `matches_remaining`: suma de `matches_remaining` de suspensiones activas
- `suspension_type`: tipo de la suspensión activa más reciente (`created_at` DESC)
- Autorización: `is_member_of(organization_id del partido)` — lectura informativa, mismo criterio que RLS de plantel

Tests SQL: `supabase/tests/035_match_roster_eligibility.sql` (6 casos)
