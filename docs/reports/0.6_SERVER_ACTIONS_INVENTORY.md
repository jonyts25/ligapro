## Brechas fase 1

1. **Confirmar asignación (oficial):** `confirmMatchOfficialAction` es **admin-only** (`match_officials` UPDATE vía RLS owner/admin). No existe RPC ni acción para que el árbitro/anotador confirme su propia fila (`assigned` → `confirmed`). **Requiere nueva RPC** (p. ej. `confirm_match_official_assignment`) + endpoint mobile.

2. **Cerrar partido (referee/scorekeeper):** `update_match_result` autoriza solo owner/admin/`tournament_admin` (Migration 022). Árbitro/anotador confirmado puede capturar eventos pero **no** cerrar marcador hoy. Si fase 1 exige cierre por oficial, **requiere extensión de RPC** o rol `tournament_admin` en campo.

3. **Mis partidos:** no hay server action; mobile debe leer vía Supabase (si RLS lo permite al oficial miembro) o **GET `/api/mobile/matches`**.

4. **Auth mobile:** login/logout vía `@supabase/supabase-js` en dispositivo; no reutilizar acciones `auth/actions.ts` (Category B).
