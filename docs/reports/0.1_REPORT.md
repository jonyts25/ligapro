## 3. Decisiones tomadas

### tsc (TS5097)

Se añadió `"allowImportingTsExtensions": true` en `tsconfig.json` (ya tiene `noEmit: true`). Los 7 imports `.ts` en tests de node:test+tsx siguen funcionando; `npm test` pasa (213 tests). `npm run build` (Next.js) OK — Next compila con su propio pipeline, no emite vía `tsc`. Alternativa descartada: quitar extensión en 7 imports (más diffs, mismo efecto).

### MatchEventForm — equivalencia sin effects

| Effect original | Reemplazo | Equivalencia |
|-----------------|-----------|--------------|
| `setMinute(suggestMatchMinute(matchStartsAt))` al cambiar `matchStartsAt` | Ajuste en render: si `matchStartsAt !== prevMatchStartsAt`, actualizar `minute` | Mismo minuto sugerido al cambiar hora de inicio del partido |
| `setSelected(null)` y `setShowSubstitution(false)` cuando `state.ok` | Tras transición `pending`: true→false con `state.ok`, limpiar selección | Tras registrar gol/tarjeta/cambio con éxito, se deselecciona jugador y cierra panel de cambio — listo para el siguiente evento |

### MatchSchedulingForm

`refreshOpenSlots` / `refreshAvailability` mueven **todo** `setState` dentro del callback async de `startOpenSlots`/`startAvail` (después de `await`), evitando setState síncrono en effect. Comportamiento igual: carga slots al montar/cambiar cancha; refresca tras error de programación.

### RosterImportSection

`key={teamId}` en wrapper + `useEffect` con fetch async (setState solo tras `await`). Equivalente al reset al cambiar equipo.

### Copy «temporada»

Solo textos visibles. **No** se tocaron: rutas `/temporadas/`, identificadores (`season_roles`, `active="temporada"`), slug fallback `"temporada"`, tablas/RPCs, tests (salvo asserts de mensajes actualizados).
