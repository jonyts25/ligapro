## Resumen

Antes de generar el fixture, el paso «generar» del asistente muestra una estimación de partidos totales, ritmo semanal (según canchas con horario configurado) y semanas aproximadas para terminar el torneo. Cálculo puro en cliente/servidor, sin migración.

## Implementación

### Función pura

`src/lib/tournament-wizard/simulator.ts` — `estimateTournamentPlan`:

| Formato | Fórmula |
|---------|---------|
| `round_robin` | n×(n−1)/2 |
| `round_robin_double` | n×(n−1) |
| `knockout` | n−1 (+ partido por 3.er lugar si n ≥ 4) |
| `groups_knockout` | Aproximado: ceil(n/4) grupos × 6 + llave eliminatoria (clasificados = grupos × advance, default 2) |

Devuelve `null` si `teamCount < 2` o `fieldsCount === 0`.

### WizardContext extendido

`getWizardContext` ahora incluye:

- `formatType` — `seasons.format_type`
- `matchDurationMinutes` — `season_rules.match_duration_minutes`
- `groupsAdvancePerGroup` — `season_rules.groups_advance_per_group`
- `fieldsCount` — canchas distintas en `season_field_blocks` (paso horarios)

### UI

`TournamentWizardGenerateStep`: tarjeta con estimación antes del botón «Generar mi torneo». Oculta si el plan es `null`. Nota de aproximación para `groups_knockout`.
