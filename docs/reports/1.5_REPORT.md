### Dependencias (via `npx expo install`)

### Navegación

- `mis-partidos.tsx` → tocar partido → `/partidos/[matchId]`
- Permiso con `can_capture_match` antes de mostrar captura

### Pantallas (descripción textual)

1. **Lista Mis partidos** — tarjetas existentes con hint “Toca para capturar”.
2. **Captura /partidos/[matchId]** — encabezado Local vs Visitante.
3. **Validación express** — lista de jugadores de ambos equipos, toque para marcar presentes, botón “Validar plantel” (`validate_match_roster`). Colapsable tras validar; re-editable.
4. **Cronómetro** — iniciar/pausar, 1er/2do tiempo, duración = `match_duration_minutes / 2`. Minuto sugerido precarga captura (editable). **No persiste** si se cierra la app.
5. **Captura Gol** — equipo (con escudo 1.4) → autor (`played`) → asistencia opcional (mismos compañeros) o “Sin asistencia”.
6. **Captura Tarjeta** — equipo → jugador `played` → amarilla/roja.
7. **Captura Cambio** — equipo → sale (`played`) → entra (no `played`, o todo el plantel si no hubo validación).
8. **Pendientes de envío** — eventos en cola local con ícono ⏳; botón “Reintentar envío”.
9. **Últimos eventos** — lista corta con “Deshacer” si &lt; 3 min (`void_match_event`); error del servidor si expira al tocar.

### Offline

- **Colas separadas** en AsyncStorage:
  - `ligapro.capture.pendingEvents` — eventos
  - `ligapro.capture.pendingRoster` — validación de plantel (una entrada por partido, reemplaza la anterior)
- Reintento automático al recuperar señal (NetInfo) + botón manual.
- Rechazo de negocio → se quita de cola y se muestra error; no reintento infinito.
- `client_dedup_key`: `crypto.randomUUID()` en runtime Expo; fallback `${Date.now()}-random` si no hay `crypto.randomUUID`.
